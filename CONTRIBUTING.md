# Contributing to Awesome Interview Skills

Thank you for your interest in contributing! 🎉

## How to Contribute

### 1. Add a New Skill

1. Fork the repository
2. Create a new branch: `git checkout -b add-skill/new-skill-name`
3. Create your skill file in the appropriate category folder under `skills/`
4. Follow the skill template format (see below)
5. Submit a Pull Request

### 2. Improve an Existing Skill

1. Fork the repository
2. Create a new branch: `git checkout -b improve/skill-name`
3. Make your changes
4. Submit a Pull Request with a clear description of what you improved

### 3. Report Issues

- Use the [Issue Tracker](../../issues) to report bugs or suggest improvements
- Use the provided issue templates

## Skill File Template

Every skill file must follow this structure:

```markdown
# Skill Title — 中文标题

> **When to Use / 使用场景**: [Clear trigger conditions]

---

## Key Concepts / 核心概念
[Core knowledge with tables/diagrams]

## Step-by-Step Framework / 分步框架
[Structured approach]

## Templates / 模板
[Fill-in-the-blank templates with examples]

## Common Mistakes / 常见错误
[Numbered list of pitfalls]

## Pro Tips / 高手技巧
[Insider knowledge]

## Practice Questions / 练习题
[Where applicable]
```

### Requirements

- **Minimum 150 lines** per skill file
- **Bilingual**: Include both English and Chinese headers
- **Practical**: Include real templates, not just theory
- **Specific**: Give concrete examples, not vague advice
- **Actionable**: The reader should be able to use it immediately

## Quality Standards

### We Accept

- ✅ New skills that cover gaps in interview preparation
- ✅ Improvements to existing skills (more examples, better templates)
- ✅ Corrections to factual errors
- ✅ Updates for new interview trends (e.g., AI-related questions)
- ✅ Translations to other languages

### We Don't Accept

- ❌ Skills with fewer than 150 lines
- ❌ Skills without templates or practical examples
- ❌ Plagiarized content
- ❌ Promotional or marketing content
- ❌ Duplicate skills that cover the same topic
