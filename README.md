### 🚀 Quick Start

#### Cursor

1. Clone this repo or copy the skill files to your project
2. In Cursor, open a chat and reference the skill:
   ```
   @skills/算法面试/leetcode-patterns.md Help me solve LeetCode 3
   ```
3. The AI will follow the framework in the skill file

#### Claude Code

1. Clone the repo:
   ```bash
   git clone https://github.com/liangzhengtao/awesome-interview-skills.git
   ```
2. Reference skills in your conversation:
   ```
   Read skills/行为面试/star-method.md and help me prepare an answer for "Tell me about a conflict you resolved"
   ```

#### Kimi Code

1. Copy skill files to your working directory
2. Reference in conversation:
   ```
   @skills/简历优化/tech-resume.md Review my resume and give feedback
   ```

#### Any AI Assistant

Simply paste the content of a skill file into your conversation, then ask your question. The AI will follow the frameworks and templates.

## 📖 How Each Skill Works

Each skill file contains:

1. **When to Use** — Clear trigger conditions
2. **Key Concepts** — Core knowledge you need
3. **Step-by-Step Framework** — Structured approach
4. **Templates** — Fill-in-the-blank templates with examples
5. **Common Mistakes** — Pitfalls to avoid
6. **Pro Tips** — Insider knowledge from experienced engineers
7. **Practice Questions** — Hands-on exercises
