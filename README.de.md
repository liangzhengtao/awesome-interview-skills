### 🚨 Schluss mit gescheiterten Vorstellungsgesprächen. 14 KI-Skills, um Ihren Traumjob bei FAANG zu bekommen.

**Vorher**: Nervös, unvorbereitet, wirre Antworten, Blackout bei Algorithmen, keine Struktur.

**Nachher**: Selbstbewusst, strukturierte Antworten, muster-basierte Problemlösung, datenbasierte Verhandlung, Angebote von Top-Unternehmen.

*Dies sind KI-Skills (`.md`-Dateien), die in **Cursor**, **Claude Code**, **Kimi Code**, **Windsurf** oder jeden KI-Coding-Assistenten geladen werden können, um Echtzeit-Interview-Coaching zu erhalten.*

### 🚀 Schnellstart

#### Cursor

1. Klonen Sie dieses Repo oder kopieren Sie die Skill-Dateien in Ihr Projekt
2. Öffnen Sie in Cursor einen Chat und referenzieren Sie den Skill:
   ```
   @skills/算法面试/leetcode-patterns.md Help me solve LeetCode 3
   ```
3. Die KI folgt dem Framework in der Skill-Datei

#### Claude Code

1. Repository klonen:
   ```bash
   git clone https://github.com/liangzhengtao/awesome-interview-skills.git
   ```
2. Skills in Ihrer Unterhaltung referenzieren:
   ```
   Read skills/行为面试/star-method.md and help me prepare an answer for "Tell me about a conflict you resolved"
   ```

#### Kimi Code

1. Kopieren Sie die Skill-Dateien in Ihr Arbeitsverzeichnis
2. Referenzieren Sie in der Unterhaltung:
   ```
   @skills/简历优化/tech-resume.md Review my resume and give feedback
   ```

#### Jeder KI-Assistent

Fügen Sie einfach den Inhalt einer Skill-Datei in Ihre Unterhaltung ein und stellen Sie Ihre Frage. Die KI folgt den Frameworks und Templates.

## 📖 Wie jeder Skill funktioniert

Jede Skill-Datei enthält:

1. **Wann verwenden** — Klare Auslösebedingungen
2. **Schlüsselkonzepte** — Notwendiges Kernwissen
3. **Schritt-für-Schritt-Framework** — Strukturierter Ansatz
4. **Templates** — Ausfüllvorlagen mit Beispielen
5. **Häufige Fehler** — Fallstricke, die vermieden werden sollten
6. **Profi-Tipps** — Insiderwissen erfahrener Ingenieure
7. **Übungsfragen** — Praktische Übungen
