### 🚨 Хватит проваливать собеседования. 14 ИИ-навыков, чтобы получить работу мечты в FAANG.

**До**: Нервы, неподготовленность, бессвязные ответы, ступор при алгоритмах, отсутствие структуры.

**После**: Уверенность, структурированные ответы, решение задач по паттернам, переговоры на основе данных, офферы от топ-компаний.

*Это ИИ-навыки (файлы `.md`), которые можно загрузить в **Cursor**, **Claude Code**, **Kimi Code**, **Windsurf** или любой ИИ-ассистент для кодирования для получения коучинга по собеседованиям в реальном времени.*

### 🚀 Быстрый старт

#### Cursor

1. Клонируйте репозиторий или скопируйте файлы навыков в ваш проект
2. В Cursor откройте чат и сошлитесь на навык:
   ```
   @skills/算法面试/leetcode-patterns.md Help me solve LeetCode 3
   ```
3. ИИ будет следовать фреймворку из файла навыка

#### Claude Code

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/liangzhengtao/awesome-interview-skills.git
   ```
2. Сошлитесь на навыки в разговоре:
   ```
   Read skills/行为面试/star-method.md and help me prepare an answer for "Tell me about a conflict you resolved"
   ```

#### Kimi Code

1. Скопируйте файлы навыков в рабочую директорию
2. Сошлитесь в разговоре:
   ```
   @skills/简历优化/tech-resume.md Review my resume and give feedback
   ```

#### Любой ИИ-ассистент

Просто вставьте содержимое файла навыка в ваш разговор и задайте вопрос. ИИ будет следовать фреймворкам и шаблонам.

## 📖 Как работает каждый навык

Каждый файл навыка содержит:

1. **Когда использовать** — Чёткие условия применения
2. **Ключевые концепции** — Необходимые базовые знания
3. **Пошаговый фреймворк** — Структурированный подход
4. **Шаблоны** — Шаблоны для заполнения с примерами
5. **Частые ошибки** — Подводные камни, которых стоит избегать
6. **Профессиональные советы** — Знания от опытных инженеров
7. **Практические вопросы** — Упражнения для практики
