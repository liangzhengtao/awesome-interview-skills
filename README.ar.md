### 🚨 توقف عن فشل المقابلات. 14 مهارة AI لمساعدتك في الحصول على وظيفة أحلامك في FAANG.

**قبل**: متوتر، غير مستعد، إجابات مبعثرة، صدمة أثناء الخوارزميات، بدون بنية.

**بعد**: واثق، إجابات منظمة، حل المشاكل بناءً على الأنماط، تفاوض مبني على البيانات، عروض عمل من أفضل الشركات.

*هذه مهارات AI (ملفات `.md`) يمكن تحميلها في **Cursor** أو **Claude Code** أو **Kimi Code** أو **Windsurf** أو أي مساعد برمجة AI للحصول على تدريب فعلي للمقابلات.*

### 🚀 البدء السريع

#### Cursor

1. استنسخ هذا المستودع أو انسخ ملفات المهارات إلى مشروعك
2. في Cursor، افتح محادثة وأشر إلى المهارة:
   ```
   @skills/算法面试/leetcode-patterns.md Help me solve LeetCode 3
   ```
3. سيتبع AI الإطار الموجود في ملف المهارة

#### Claude Code

1. استنسخ المستودع:
   ```bash
   git clone https://github.com/liangzhengtao/awesome-interview-skills.git
   ```
2. أشر إلى المهارات في محادثتك:
   ```
   Read skills/行为面试/star-method.md and help me prepare an answer for "Tell me about a conflict you resolved"
   ```

#### Kimi Code

1. انسخ ملفات المهارات إلى دليل عملك
2. أشر إليها في المحادثة:
   ```
   @skills/简历优化/tech-resume.md Review my resume and give feedback
   ```

#### أي مساعد AI

ببساطة الصق محتوى ملف المهارة في محادثتك، ثم اطرح سؤالك. سيتبع AI الأطر والقوالب.

## 📖 كيف تعمل كل مهارة

كل ملف مهارة يحتوي على:

1. **متى تُستخدم** — شروط تشغيل واضحة
2. **المفاهيم الأساسية** — المعرفة الأساسية التي تحتاجها
3. **إطار خطوة بخطوة** — نهج منظم
4. **القوالب** — قوالب تملأ الفراغ مع أمثلة
5. **الأخطاء الشائعة** — أخطاء يجب تجنبها
6. **نصائح المحترفين** — معرفة داخلية من مهندسين ذوي خبرة
7. **أسئلة التدريب** — تمارين عملية
