### 🚨 もう面接で失敗しない。FAANG入社を実現する14のAIスキル。

**Before**: 緊張、準備不足、だらだらした回答、アルゴリズムで頭が真っ白、構成力なし。

**After**: 自信、構造化された回答、パターンベースの問題解決、データ駆動のネゴシエーション、一流企業からのオファー。

*これらのAIスキル（`.md` ファイル）は **Cursor**、**Claude Code**、**Kimi Code**、**Windsurf**、または任意のAIコーディングアシスタントに読み込むことで、リアルタイムの面接コーチングを受けられます。*

### 🚀 クイックスタート

#### Cursor

1. このリポジトリをクローンするか、スキルファイルをプロジェクトにコピー
2. Cursorでチャットを開きスキルを参照：
   ```
   @skills/算法面试/leetcode-patterns.md Help me solve LeetCode 3
   ```
3. AIがスキルファイルのフレームワークに従って回答

#### Claude Code

1. リポジトリをクローン：
   ```bash
   git clone https://github.com/liangzhengtao/awesome-interview-skills.git
   ```
2. 会話でスキルを参照：
   ```
   Read skills/行为面试/star-method.md and help me prepare an answer for "Tell me about a conflict you resolved"
   ```

#### Kimi Code

1. スキルファイルをワーキングディレクトリにコピー
2. 会話で参照：
   ```
   @skills/简历优化/tech-resume.md Review my resume and give feedback
   ```

#### その他のAIアシスタント

スキルファイルの内容を会話に貼り付けて、質問を投げかけるだけ。AIがフレームワークとテンプレートに従って回答します。

## 📖 各スキルの仕組み

各スキルファイルには以下が含まれます：

1. **使用タイミング** — 明確なトリガー条件
2. **重要概念** — 必要なコア知識
3. **ステップバイステップフレームワーク** — 構造化されたアプローチ
4. **テンプレート** — 埋め込み式テンプレートと具体例
5. **よくあるミス** — 避けるべき落とし穴
6. **プロのヒント** — ベテランエンジニアからの実践的な知見
7. **練習問題** — 実践的な演習
