### 🚨 면접에서 떨어지지 마세요. FAANG에 입사할 수 있도록 도와주는 14가지 AI 스킬.

**이전**: 긴장, 준비 부족, 두서없는 답변, 알고리즘에서 막힘, 구조 없음.

**이후**: 자신감, 구조화된 답변, 패턴 기반 문제 해결, 데이터 기반 협상, 최고 기업의 합격.

*이것들은 **Cursor**, **Claude Code**, **Kimi Code**, **Windsurf**, 또는 어떤 AI 코딩 어시스턴트에든 로드하여 실시간 면접 코칭을 받을 수 있는 AI 스킬(`.md` 파일)입니다.*

### 🚀 빠른 시작

#### Cursor

1. 이 저장소를 클론하거나 스킬 파일을 프로젝트에 복사하세요
2. Cursor에서 채팅을 열고 스킬을 참조하세요:
   ```
   @skills/算法面试/leetcode-patterns.md Help me solve LeetCode 3
   ```
3. AI가 스킬 파일의 프레임워크를 따릅니다

#### Claude Code

1. 저장소 클론:
   ```bash
   git clone https://github.com/liangzhengtao/awesome-interview-skills.git
   ```
2. 대화에서 스킬 참조:
   ```
   Read skills/行为面试/star-method.md and help me prepare an answer for "Tell me about a conflict you resolved"
   ```

#### Kimi Code

1. 스킬 파일을 작업 디렉토리에 복사
2. 대화에서 참조:
   ```
   @skills/简历优化/tech-resume.md Review my resume and give feedback
   ```

#### 어떤 AI 어시스턴트든

스킬 파일의 내용을 대화에 붙여넣고 질문하세요. AI가 프레임워크와 템플릿을 따릅니다.

## 📖 각 스킬의 작동 방식

각 스킬 파일에는 다음이 포함됩니다:

1. **사용 시점** — 명확한 트리거 조건
2. **핵심 개념** — 필요한 핵심 지식
3. **단계별 프레임워크** — 구조화된 접근 방식
4. **템플릿** — 예시가 포함된 빈칸 채우기 템플릿
5. **흔한 실수** — 피해야 할 함정
6. **프로 팁** — 숙련된 엔지니어의 인사이트
7. **연습 문제** — 실습 연습
