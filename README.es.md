### 🚨 Deja de fracasar en las entrevistas. 14 habilidades IA para conseguir tu trabajo soñado en FAANG.

**Antes**: Nervios, sin preparación, respuestas desordenadas, bloqueo en algoritmos, sin estructura.

**Después**: Confianza, respuestas estructuradas, resolución de problemas por patrones, negociación basada en datos, ofertas de empresas top.

*Estas son habilidades IA (archivos `.md`) que se pueden cargar en **Cursor**, **Claude Code**, **Kimi Code**, **Windsurf** o cualquier asistente IA de código para recibir coaching de entrevistas en tiempo real.*

### 🚀 Inicio rápido

#### Cursor

1. Clona este repositorio o copia los archivos de habilidad a tu proyecto
2. En Cursor, abre un chat y referencia la habilidad:
   ```
   @skills/算法面试/leetcode-patterns.md Help me solve LeetCode 3
   ```
3. La IA seguirá el framework del archivo de habilidad

#### Claude Code

1. Clona el repositorio:
   ```bash
   git clone https://github.com/liangzhengtao/awesome-interview-skills.git
   ```
2. Referencia las habilidades en tu conversación:
   ```
   Read skills/行为面试/star-method.md and help me prepare an answer for "Tell me about a conflict you resolved"
   ```

#### Kimi Code

1. Copia los archivos de habilidad a tu directorio de trabajo
2. Referencia en la conversación:
   ```
   @skills/简历优化/tech-resume.md Review my resume and give feedback
   ```

#### Cualquier asistente IA

Simplemente pega el contenido de un archivo de habilidad en tu conversación y haz tu pregunta. La IA seguirá los frameworks y plantillas.

## 📖 Cómo funciona cada habilidad

Cada archivo de habilidad contiene:

1. **Cuándo usarla** — Condiciones de activación claras
2. **Conceptos clave** — Conocimiento fundamental necesario
3. **Framework paso a paso** — Enfoque estructurado
4. **Plantillas** — Plantillas para completar con ejemplos
5. **Errores comunes** — Errores frecuentes a evitar
6. **Consejos de expertos** — Conocimiento interno de ingenieros experimentados
7. **Preguntas de práctica** — Ejercicios prácticos
