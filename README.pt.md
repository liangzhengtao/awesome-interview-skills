### 🚨 Pare de reprovar em entrevistas. 14 habilidades de IA para conquistar seu emprego dos sonhos na FAANG.

**Antes**: Nervoso, despreparado, respostas desorganizadas, travando em algoritmos, sem estrutura.

**Depois**: Confiante, respostas estruturadas, resolução de problemas baseada em padrões, negociação baseada em dados, ofertas de grandes empresas.

*Estas são habilidades de IA (arquivos `.md`) que podem ser carregadas no **Cursor**, **Claude Code**, **Kimi Code**, **Windsurf** ou qualquer assistente de código com IA para receber coaching de entrevista em tempo real.*

### 🚀 Início Rápido

#### Cursor

1. Clone este repo ou copie os arquivos de habilidades para seu projeto
2. No Cursor, abra uma conversa e referencie a habilidade:
   ```
   @skills/算法面试/leetcode-patterns.md Help me solve LeetCode 3
   ```
3. A IA seguirá o framework do arquivo de habilidade

#### Claude Code

1. Clone o repo:
   ```bash
   git clone https://github.com/liangzhengtao/awesome-interview-skills.git
   ```
2. Referencie habilidades na sua conversa:
   ```
   Read skills/行为面试/star-method.md and help me prepare an answer for "Tell me about a conflict you resolved"
   ```

#### Kimi Code

1. Copie os arquivos de habilidades para seu diretório de trabalho
2. Referencie na conversa:
   ```
   @skills/简历优化/tech-resume.md Review my resume and give feedback
   ```

#### Qualquer Assistente de IA

Basta colar o conteúdo de um arquivo de habilidade na sua conversa, depois faça sua pergunta. A IA seguirá os frameworks e templates.
